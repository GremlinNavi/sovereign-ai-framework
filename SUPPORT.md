# Support

This project is maintained on a best-effort basis. Public availability does not imply
a service-level commitment, professional advice, or guaranteed compatibility.

Before asking for help:

1. read the README and linked documentation;
2. search existing issues; and
3. remove credentials, private repository details, and personal data.

For a reproducible defect, open an issue with the operating system, PowerShell or
Python version as applicable, exact command, expected result, actual result, and a
minimal sanitized example. For a usage question, use an issue labelled `question`
or `support` when those labels are available.

Do not report vulnerabilities or real secrets in public. Follow
[SECURITY.md](SECURITY.md). Conduct concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
