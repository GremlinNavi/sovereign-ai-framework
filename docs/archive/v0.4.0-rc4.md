# v0.4.0-rc4 archive record

This is a public-safe source-candidate record for `v0.4.0-rc4` (`0.4.0rc4` as the
Python package version). It is not evidence of a hosted release, tag, source ZIP,
Windows executable, or checksum manifest.

## Candidate scope

RC4 adds an opt-in Windows PowerShell bootstrap and guarded Git update workflow, with
documentation that preserves the project's local-first, configurable-backend
boundary. It does not bundle or install an inference runtime, download model weights,
change a user's global PowerShell policy, or add a cloud fallback.

The scripts and documentation are source changes, not proof that a Windows build,
Steam Deck build, or any third-party runtime has been tested or released.

## Public title normalization

The canonical public title is **Eternal Thread — Sovereign AI Demonstrator**. The
short product name is **Eternal Thread**. `sovereign-ai-framework` remains the
technical repository slug and architecture descriptor, not a competing public product
name. This normalization updates user-facing application strings, release metadata,
and documentation only; it does not change the `eternal-thread` package name, licence,
release status, inference-runtime selection, or model selection.

The title-normalization update completed Python compilation, configuration validation,
and an isolated test run with 53 passed on 2026-09-01.
