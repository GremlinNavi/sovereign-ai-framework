# v0.4.0-rc4 archive record

This is a public-safe source-candidate record for `v0.4.0-rc4` (`0.4.0rc4` as the

## Candidate scope

RC4 adds an opt-in Windows PowerShell bootstrap and guarded Git update workflow, with
documentation that preserves the project's local-first, configurable-backend
boundary. It does not bundle or install an inference runtime, download model weights,
change a user's global PowerShell policy, or add a cloud fallback.

The scripts and documentation are source changes, not proof that a Windows build,
Steam Deck build, or any third-party runtime has been tested or released.
