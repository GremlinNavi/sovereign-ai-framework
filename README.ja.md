# OSWAP AI Demonstrator

[English](README.md) · [Français canadien](README.fr-CA.md) · 日本語 · [言語方針](LANGUAGES.md)

ローカルファースト、監査可能、人間による管理を重視した AI 支援研究のためのカナダ発リファレンス実装です。

OSWAP AI Demonstrator は、交換可能な推論バックエンドを備えたローカルファーストの研究フレームワークです。AI のツール呼び出し、会話履歴の検索、ローカル知識の検索、公開 Web の調査、証拠評価、出典を重視した引用、信頼度評価、汎用 `.txt` 会話エクスポートを組み合わせます。

作成者: Nemi Prowse

状態: v0.4 Release Candidate 3 は、ポータブル・フレームワークの開発版です。カナダ政府の製品、サービス、承認済みシステム、または本番環境への導入ではありません。

## OSWAP との関係

Open-Source World Access Project (OSWAP) は、オープンソース・ソフトウェアへのアクセス、発見、保存、および関連ツールを扱う、より広範なプロジェクトです。

OSWAP AI Demonstrator は、OSWAP に含まれる AI デモンストレーター・コンポーネントです。OSWAP の一部として、独自の実装・リリース境界を維持します。

OSWAP は、将来のインフラ向けに `oswap.ca`、`oswap.jp`、`oswap.us` を登録しています。本書は、これらのドメイン上の OSWAP Web サイト、Git エンドポイント、API、その他の公開サービスを、現在導入済みまたはオンラインとは表現しません。

このプロジェクト向けに計画されている公開ホスト名は次の3つです。

- `ai.oswap.ca` — 計画中。現在オンラインではありません
- `ai.oswap.jp` — 計画中。現在オンラインではありません
- `ai.oswap.us` — 計画中。現在オンラインではありません

この3つは、主系とミラーという階層ではなく、対等なピア・エンドポイントとして設計されています。DNS、TLS、ルーティング、ホスティング、Git プロトコル処理の導入と検証が完了するまでは、稼働中サービスとして扱いません。

予定されているエンドポイント仕様と Order of Operations によるリポジトリ・アドレッシング例については [OSWAP_AI_ENDPOINTS.ja.md](OSWAP_AI_ENDPOINTS.ja.md) を参照してください。

## 予定されている Git アクセス

インフラの導入と検証後、将来の OSWAP エンドポイントでは読み取り専用の Git アクセスを提供する予定です。

導入前の構文例では、実在する OSWAP ドメインを現在利用可能なネットワーク先のように見せないため、予約済みの `.invalid` ドメインを使用します。

```text
git clone https://ai.oswap.invalid
git pull https://ai.oswap.invalid main
```

上記は意図的に非稼働の例です。現在の clone 手順では、検証済みの GitHub または GitLab のリポジトリ URL を使用します。

## 技術的な原則

このフレームワークは、主に次の原則を重視します。

- ローカル実行とプライバシーを既定とする設計
- 交換可能な AI バックエンド
- ローカル知識と会話履歴の検索
- 明示的な同意管理
- ツール呼び出しのローカル監査ログ
- 人間のレビューを必須とする証拠分析
- UTF-8 テキストによる会話エクスポート
- 単一ベンダーに依存せず、既知の良好なソフトウェア状態を保存できる構成

Ollama は対応バックエンドのひとつですが、このフレームワークそのもののアイデンティティではありません。必要な機能と互換性がある限り、推論アダプターは置き換え可能です。

## プライバシーと安全性

会話履歴、埋め込み、取得した Web ページは、設定とユーザーの同意に応じてローカルに保存されます。公開インターネットへアクセスする Web リクエストは、必然的に端末外へ送信されます。

本プロジェクトの安全対策は実用的なアプリケーション層の防御であり、完全な安全性を保証するものではありません。公開利用や組織的な導入には、人間による評価と導入環境に応じたレビューが必要です。
