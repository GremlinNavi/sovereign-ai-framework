# Sovereign AI Demonstrator

[English](README.md) · [Français canadien](README.fr-CA.md) · 日本語 · [言語方針](LANGUAGES.md)

ローカルファースト、監査可能、人間による管理を重視した AI 支援研究のためのカナダ発リファレンス実装です。

Sovereign AI Demonstrator は、交換可能な推論バックエンドを備えたローカルファーストの研究フレームワークです。AI のツール呼び出し、会話履歴の検索、ローカル知識の検索、公開 Web の調査、証拠評価、出典を重視した引用、信頼度評価、汎用 `.txt` 会話エクスポートを組み合わせます。

作成者: Nemi Prowse

状態: v0.4 Release Candidate 3 は、ポータブル・フレームワークの開発版です。カナダ政府の製品、サービス、承認済みシステム、または本番環境への導入ではありません。

## OSWAP との関係

Open-Source World Access Project (OSWAP) は、オープンソース・ソフトウェアへのアクセス、発見、保存を目的とする別個の取り組みです。

Sovereign AI Demonstrator は独立したプロジェクト名を維持します。OSWAP はこのデモンストレーターの改名ではありません。

OSWAP は `oswap.ca`、`oswap.jp`、`oswap.us` を所有しています。このプロジェクト向けに計画されている OSWAP 管理下の公開エンドポイントは次の3つです。

- `https://ai.oswap.ca`
- `https://ai.oswap.jp`
- `https://ai.oswap.us`

この3つは、主系とミラーという階層ではなく、対等なピア・エンドポイントとして設計されています。DNS、TLS、ルーティング、Git プロトコル処理の導入と検証が完了するまでは、稼働中のサービスとして表現しません。

予定されているエンドポイント仕様と Order of Operations によるリポジトリ・アドレッシング例については [OSWAP_AI_ENDPOINTS.ja.md](OSWAP_AI_ENDPOINTS.ja.md) を参照してください。

## 予定されている Git アクセス

インフラの導入と検証後、OSWAP エンドポイントでは読み取り専用の Git アクセスを提供する予定です。

```text
git clone https://ai.oswap.ca
git clone https://ai.oswap.jp
git clone https://ai.oswap.us
```

既存の Git ワーキングツリーからは、次のような利用を想定しています。

```text
git pull https://ai.oswap.ca main
git pull https://ai.oswap.jp main
git pull https://ai.oswap.us main
```

これらは、実際の Git 操作による検証が完了するまではインフラ上の目標です。

## 技術的な原則

このフレームワークは、主に次の原則を重視します。

- ローカル実行とプライバシーを既定とする設計
- 交換可能な AI バックエンド
- ローカル知識と会話履歴の検索
- 明示的な同意管理
- ツール呼び出しのローカル監査ログ
- 人間のレビューを必須とする証拠分析
- UTF-8 テキストによる会話エクスポート
- 単一ベンダーに依存せず、既知の良好なソフトウェア状態を保存できる構成

Ollama は対応バックエンドのひとつですが、このフレームワークそのもののアイデンティティではありません。必要な機能と互換性がある限り、推論アダプターは置き換え可能です。

## プライバシーと安全性

会話履歴、埋め込み、取得した Web ページは、設定とユーザーの同意に応じてローカルに保存されます。公開インターネットへアクセスする Web リクエストは、必然的に端末外へ送信されます。

本プロジェクトの安全対策は実用的なアプリケーション層の防御であり、完全な安全性を保証するものではありません。公開利用や組織的な導入には、人間による評価と導入環境に応じたレビューが必要です。
